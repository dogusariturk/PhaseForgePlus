# Test data

Third-party files in this directory are kept unchanged. Each one is listed below with its source and license.

## Al–Ti antisite control (`AlTi-08Wit.tdb`)

`AlTi-08Wit.tdb` is an unchanged copy from the `sgte-binary` collection in `orchid-calphad/open-tdb`, distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Collection: Bengt Hallstedt, “The SGTE collection of binary datasets,” *Calphad* 89 (2025) 102833, doi:10.1016/j.calphad.2025.102833.

Assessment: V. T. Witusiewicz, A. A. Bondar, U. Hecht, S. Rex and T. Ya. Velikanova, *Journal of Alloys and Compounds* 465 (2008), 64–77.

The test uses the two-sublattice `ALTI3_D019` model at 1468 K and x(Ti) = 0.695 and 0.715. These are numerical regression conditions, not new experimental observations. No assessment parameters were changed.
